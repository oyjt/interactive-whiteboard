# 互动白板

Vue 3 + TypeScript + Fabric 6 实现的互动白板。

## 功能

- 自由绘制、形状、箭头、文本、选择与对象擦除。
- 画笔尺寸 1–40，常用颜色、自定义颜色、笔迹预览。
- 独立橡皮擦尺寸 1–80；画笔设置本地记忆。
- 撤销/重做（每页最多 50 步）、对象复制粘贴、键盘移动与删除。
- 示例课件翻页、每页独立批注及历史、页面删除。
- 清除批注保留课件背景，当前页导出 2 倍分辨率 PNG。
- 同页第二画布同步预览，仅在内容变更后更新。
- Excalidraw 风格浮动工具栏、属性面板、主菜单及底部控制区。

## 开发

Node.js 22.18+（建议 Node 24），pnpm 10.20.0。

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

## 使用约定

- 选择画笔或橡皮擦后，左上属性面板显示颜色和尺寸设置。设置应用于后续绘制，不修改已有对象、不占用撤销步骤。
- 笔宽采用画布单位，缩放时随内容一起缩放。画笔和橡皮擦尺寸分别保存。
- 橡皮擦命中后删除整个对象，尚不支持局部像素擦除。
- 清除批注可撤销；页面删除需确认，无法撤销。课件使用内置 JPEG，并非 PPTX 解析。
- 画布获得焦点后：Ctrl/⌘+C、V 复制粘贴；Ctrl/⌘+Z 撤销；Ctrl+Y 或 Ctrl/⌘+Shift+Z 重做；方向键移动；Delete/Backspace 删除。
- 画布获得焦点后：1–8、0 或 V/R/O/A/L/P/T/E 切换工具，Esc 返回选择工具。
- 输入框和文本编辑期间不接管这些快捷键。
- 当前仅保存画笔偏好；白板和课件批注在本次会话内保留，刷新前请导出 PNG。
- 同步预览是本地演示，不包含网络传输或多人协作。图片导出要求图片源允许跨域访问。

## 验证

```sh
pnpm test
pnpm build
pnpm exec playwright install chromium --only-shell
pnpm test:browser
```

`test` 使用 Node 内置测试运行器，覆盖历史分支与容量、配置校验、箭头序列化。
`test:browser` 自动启动本地 Vite，通过 Playwright 验证实际绘制、设置持久化、撤销、复制粘贴、翻页、页面删除与 PNG 导出。
浏览器测试读取 Vue 开发实例以检查画布内容，仅在测试脚本中使用，应用不暴露测试接口。
CI 在 Node 24 上执行以上检查。

调整范围、验收项和后续计划见 [调整清单](docs/adjustment-plan.md)。

# 白板调整清单与实施计划

参考 paint-board 的交互设计，保留 Vue 3 + Fabric 6；不迁移其 React/Fabric 5 代码。

## 本次实施

- [x] 画笔尺寸：1–40，默认 5，快捷档位 2/5/10/20，采用画布单位。
- [x] 画笔颜色：8 个常用色、自定义颜色、选中状态；默认红色。
- [x] 属性面板：画笔与线条、箭头、形状共用颜色和线宽，实时预览；橡皮擦固定范围，无设置面板。
- [x] 配置记忆：本地保存设置，校验异常数据，存储不可用时仍可绘制。
- [x] 历史记录：统一内容提交、初始快照、去重、分支截断、异步恢复锁。
- [x] 箭头注册序列化类型；多次粘贴创建独立对象；快捷键支持 macOS。
- [x] PPT 页面独立保存批注，统一翻页入口；清除批注保留背景；完成页面删除。
- [x] 同步仅响应内容变更，串行恢复最新快照，移除本地压缩往返。
- [x] 画布、事件、快捷键卸载清理；复杂实例使用 shallowRef。
- [x] 当前页 PNG 导出，包含 PPT 背景。
- [x] 构建、核心回归检查及中文使用说明。

## 验收

1. 改色、改尺寸后下一笔生效，已有内容不变，配置操作不占用撤销步骤。
2. 工具切换、刷新后恢复配置；画笔和橡皮擦的尺寸互不污染。
3. 绘制、删除、移动、清屏可撤销；撤销后新绘制不再保留旧重做分支。
4. 箭头在撤销恢复及镜像画布中仍是箭头。
5. 不同 PPT 页批注互不影响，返回页面能恢复；快速操作不会异步覆盖。
6. PNG 导出成功；无新增运行时依赖。

## 实施结果

- 已完成上述本次实施项，新增 `BrushSettings.vue`、设置校验与快照历史模块。
- 运行时依赖保持不变；开发依赖新增 Playwright，用于浏览器回归。
- Node 内置测试 3 项通过：历史分支与容量、配置校验、箭头序列化。
- 浏览器回归通过：设置生效及记忆、尺寸隔离、撤销分支、箭头和擦除属性恢复、重复粘贴、键盘删除撤销、页面隔离、保留背景清屏、PNG 导出、缩略图跳转和页面删除。
- 同步改为内容提交后串行恢复最新快照；主 JS 由约 500 kB 降到约 465 kB（gzip 152 → 141 kB）。
- 新增 CI：锁文件安装、核心测试、构建、浏览器回归。远程执行结果需以 GitHub Actions 为准。
- 本地浏览器检查使用 Chromium 138；本环境默认 Playwright 浏览器下载不可用，使用独立浏览器可执行文件完成检查。CI 使用 Playwright 配套浏览器。
